# PC 端交互原型实施清单

**目标**：在 ui/desktop 提供可点击的桌面原型、1440×960 页面 PNG、画廊与设计说明。
**结构**：延续现有静态 HTML/CSS/JS 原型，复用 ui/shared/tokens.css、ui/shared/components.js。桌面使用独立布局与按页面拆分的交互模块。
**依据**：doc/LIFE_CANVAS_V1_REQUIREMENTS.md、ui/mobile/docs/DESIGN.md 及本对话中的用户修订；日记不设预览和手动保存，用户修订优先于原需求文档。

## 约束
- 左侧四个主入口：饮食记录、日记、AI 对话、设置；首页为当天三餐。
- 沿用 Life Canvas 名称、纸白与墨绿、宋体标题；命名提案仍可单独查看。
- 未知用量保持空值、估计显示约；不添加营养、评分或仪表盘。
- 日记全屏专注、逐个添加标签、图标隐私提示、自动保存；日历支持年月。
- AI 写入必须先预览确认，结果可撤销；欢迎态仅显示于新对话。
- 核心验收宽度 1024、1280、1440、1920；支持减少动态效果与键盘关闭。

## 文件分工与步骤
- [x] desktop/index.html、desktop/styles/desktop.css、desktop/scripts/app.js：桌面骨架、共享控件、日历、弹层与导航。
- [x] desktop/scripts/meals.js：三餐、历史筛选、编辑抽屉、校验、未吃 / 删除与撤销。
- [x] desktop/scripts/journal.js：分栏、专注模式、富文本、元数据下拉和本机自动保存。
- [x] desktop/scripts/assistant.js：会话列表、新对话、消息、待确认修改、取消与撤销。
- [x] desktop/scripts/settings.js：资料、外观、设备、AI 记忆、桌面导入导出流程。
- [x] desktop/gallery.html、desktop/scripts/gallery.js、desktop/tools/export.cjs：页面画廊、独立打开、截图和总览。
- [x] README.md：设计取舍、体验路径和原型边界；手机总览增加 PC 入口。

## 验证重点
- 日期跨年、闰年、翻看和确认分离，日记日期筛选不改变三餐日期。
- 餐次编辑保留其他明细；空名称与错误用量提示；退出未保存编辑需确认。
- 日记输入不重绘编辑器，中文组合输入不中断；自动保存失败不伪成功。
- AI 未确认不写入，新建会话取消旧回复定时器，已变动记录不应用旧建议。
- 导入预检展示重复 / 冲突、明确确认后执行；原型仅处理演示格式。
- 逐页视觉检查、尺寸检查、资源加载检查后导出最终图片。
