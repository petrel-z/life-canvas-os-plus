# Life Canvas · 手机端设计 03

2026-10-21。依据 [V1 需求](../../../doc/LIFE_CANVAS_V1_REQUIREMENTS.md) 与本轮用户明确的优先级：可用性 → 一致性 → 品牌感 → 情绪体验。

## 本轮视觉方向：生活手帐

用户希望在第二版可用性的基础上，增加辨识度和设计品质。本轮自主选择 UI 世界中的植物、阅读、日历和组件作品作为形式参考，具体分析见 [参考与取舍](REFERENCES.md)。这些参考只用于研究，不复制图片或整套页面。

- **首页是每日记录页**：品牌字标和细线建立页眉；大日期明确当前记录归属；圆形选中日期；已记录餐次用线条整理；下一餐以反白区域突出。三餐名称、食物、用量保持首屏可见。
- **日记是有层次的纸页**：最新一篇使用浅纸色与大日期，历史条目使用更轻的日期侧栏；正文继续使用系统黑体，阅读信息不靠装饰承载。
- **助手以对话为中心**：新对话以小尺寸品牌图标、简短引导语和一行次要说明呈现，不使用整块提示背景；示例问题靠近输入框，历史会话收进左上角；开始对话后辅助内容退出，写入确认继续展示前后差异。
- **编辑是安静的工作区**：食物行增加同源线性图标，标题与数值有明确层级，选填信息折叠，底部右侧保存。
- **个人页是一张资料卡**：墨绿色资料区与设置分组形成主次，不引入会员、积分或无依据的健康分数。

本轮将高级感落实在字形、字号对比、对齐、色彩比例、纸页与分隔线的节奏上。动效依然短促，无循环装饰效果。

## 页面与操作规则

| 设计决定 | 页面中的落实 |
| --- | --- |
| 首屏回答「吃了什么、多少、还缺什么」 | 首页直接列出三餐及用量；估计显示「约」，未知显示「补用量」；没有占用首屏的插画和宣传文案 |
| 高频操作就近 | 首页一点击进入用量编辑；一点击开始记录某餐；日记标题旁直接新建 |
| 页面只有明确的主次 | 墨绿色用于品牌与关键操作；已记录餐次的「编辑」为次要文字按钮；多个空餐次仅第一个使用反白区域 |
| 编辑优先处理核心字段 | 餐次页先显示食物；日期与餐次为独立辅助弹层；备注、照片和食物补充信息按需展开 |
| 保存位置一致 | 餐次、食物、资料、时区、记忆编辑在底部右侧保存；日记为自动保存，不设保存按钮；返回左上，关闭弹层右上 |
| 状态不依赖猜测 | 未记录、明确未吃、待补充使用明确文字；离线说明未保存；估计用量不伪装为准确值 |
| 错误可恢复 | 餐次保存、整餐删除、标记未吃、日记删除和 AI 修改后提供 8 秒撤销；餐次离开未保存表单前提示；日记以自动保存及输入撤销保护内容 |
| 操作过程可见 | 保存演示显示短暂加载并禁用重复提交；成功和失败有反馈；食物校验错误显示在输入旁 |
| AI 决定保持可见 | 修改前后并排呈现；确认和取消固定在底部；批准前不写入，拒绝不改记录；记录变化后阻止应用旧提议 |
| 组件采用同一来源 | 全部页面及组件目录共用 tokens.css、prototype.css、components.js |

「一点击」指进入对应编辑入口，不包含输入和保存步骤。查看三餐不需要进入详情页。估计和未知不是错误，不阻止保存已有事实。

## 信息结构

四个一级入口固定为「饮食、日记、AI、我的」。没有额外的首页、评分、营养计算、洞察或社交入口。

- 饮食：三餐 → 食物编辑；历史记录 → 日期 / 餐次 / 食物筛选与补记。
- 日记：列表 / 搜索 → 全屏新建或编辑；正文自动保存；格式在底部，心情、标签、私密设置、修订与删除在右上角下拉；移除预览功能。
- AI：常用示例 / 最近会话 → 修改预览 → 确认或取消；单次日记授权在附件入口。
- 我的：偏好设置、数据与 AI、账号。低频功能用同一种设置行承载，新增设置不需重做主导航。

## 动效与适配

按压 120ms、页面淡入 160ms、底部弹层 240ms。页面切换不再加位移；弹层只保留 24px 短距离引导；没有循环装饰动画。系统与应用的减少动态效果任一开启，就取消过渡。加载旋转只在等待明确操作结果时出现。

内容区独立滚动，底部导航和保存栏固定。日期条在极窄尺寸内可横向滑动，不撑宽页面。重要文字与用量不做截断，设置行的低优先级值可以省略。短视口仍能触达保存操作；日记底部格式工具栏适配可视视口高度，正文区域独立滚动。

## 容错细节

- 表单尚未保存：返回触发「继续编辑 / 放弃修改」，不静默丢失内容。食物弹层单独保护其输入。
- 录入不完整：名称必填；已知数量须大于零；未知数量保持空值，不转成 0；单位原样保留。
- 保存：对已有明细进行追加或修改；进入加载状态后阻止重复提交。移动日期与餐次前检查目标是否已有记录。
- 未吃与删除：未吃清空明细并明确标记；删除恢复为未记录。两者有确认和撤销。
- 离线：不修改已保存的示例数据；保留当前页输入，不承诺刷新或退出后的恢复。
- 冲突：显示最新记录，用户决定保留草稿继续核对，或确认放弃草稿。
- 撤销：这是原型内存状态回退。正式产品需要服务端授权、版本检查和对应反向操作，不能将本地回退当成真实多端撤销。

## 交付范围

21 张手机画面、核心 / 全量总览、组件规范图和可交互 HTML。新增和调整均在 ui 目录内，产品 V1 功能范围没有扩张。

原型未连接后端：登录、云同步、上传、实际 AI、邮箱、权限与后台任务为正式开发事项。AI 确认有效期为示例文案，日记修订为固定示例，导出为 demo ZIP。原生键盘、读屏、动态字体、照片处理、真正的多端冲突与数据安全仍须在 Expo 与真机阶段验收。

## 验证范围

浏览器交互检查包含：快捷补用量、保存 / 加载 / 撤销、原单位与小数保留、未知值、删除 / 未吃、表单离开提醒、日记心情与私密设置、AI 批准 / 拒绝 / 撤销、离线与冲突、主题与减少动态效果、画廊与共享组件、导出下载。

布局检查覆盖 320、360、393、430px 宽度，以及 393 × 540 短视口。手机 PNG 均为 786 × 1704。浏览器检查不等同于原生无障碍认证或后端业务验收。

第三版补充检查：辅助文字在纸页底色上的对比度约 4.56:1，待补充文字与对应底色约 4.72:1；深色模式同时定义反白前景，防止浅主色上的文字反差不足。这是具体颜色组合检查，不代表完成全部无障碍审计。

## 日记编辑补充 · 2026-10-21

依据用户指定的编辑方式：正文充分利用全屏空间，标题和正文聚焦时去掉输入边框与外圈，格式按钮保留键盘焦点提示。设置从右上角向下展开，点击外部或 Escape 收起；不遮蔽为底部大弹层。

正文支持小标题、加粗、斜体、列表和引用，格式按键作用于当前选区；输入期间不重新生成编辑 DOM，以保留光标、滚动位置和中文输入状态。撤销作用于输入 / 格式的浏览器编辑历史。

自动保存使用 650ms 防抖，返回和页面离开时同步保存当前内容。状态区区分自动保存、保存中、已保存到本机、保存失败；保存失败时留在编辑页，可点状态重试。创建新日记后写入地址中的条目标识，刷新继续同一篇。空白新日记不创建记录。设置和富文本随正文一起保存，保存失败不假定成功。

当前原型仅持久化日记到本浏览器 localStorage，无账号隔离或云同步；正式版本需要安全持久化、服务器修订和冲突控制。HTML 存储只保留允许的结构标签，粘贴按纯文本处理。浏览器编辑命令适合本次可交互原型，正式移动端需要原生或成熟富文本编辑器。

## 交互细节补充 · 2026-10-21

- 标签逐个添加：回车或加号提交一个标签，标签旁的关闭按钮独立移除；重复与逗号分隔输入就近提示。添加、移除沿用日记自动保存。中文组合输入中的回车不提前提交标签。
- 日期选择：顶部年份与月份可直接选择，左右箭头按月翻页，支持跨年和闰年；原型支持 1900–2100 年。翻看与取消都不修改已选日期，点具体日期才应用；日记筛选与饮食日期相互独立，可清除筛选。
- 日记隐私：列表只保留小锁图标，提供读屏名称与悬停说明；详细说明仍在日记设置中。
- 助手新对话：小尺寸品牌图标、23px 宋体引导语与 12px 次要说明，直接融入背景；两条文字示例靠近固定输入框。已有消息时隐藏欢迎内容，点击新建后重新显示；会话历史在导航左侧。

本轮检查覆盖标签增删与刷新恢复、重复输入和中文输入组合、跨年与闰年、日期筛选和取消、AI 查询与确认 / 取消 / 撤销，以及 320–430px 宽度和短视口。
