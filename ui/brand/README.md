# 产品名称与图标提案

设计日期：2026-10-21。结合当前产品的三餐记录、日记和生活助手，以及纸白、墨绿、安静耐看的手机界面，推荐 **一日里 / YIRILI**。

[交互提案](index.html) · [方案总览](exports/brand-overview.png) · [完整设计稿](exports/brand-study.png) · [素材包](exports/brand-assets.zip)

## 首选：一日里

读音：yī rì lǐ。品牌句：**把日常，一点点收好。**

一日三餐、一页心情，都放在一日里。三个常用字，不要求用户理解额外概念。名字能容纳饮食、日记与生活助手，后续增加其他日常记录仍然适用。YIRILI 是中文名称的拼音写法。

图标名为「一页日光」。以圆润的「日」字形成记录页，横线整理一天的片段，杏色圆点代表一束日光。主图形不依赖文字、细线或渐变；单色版本将圆点合并为同色，也保持完整。

- 主色：墨绿 `#284F40`，与当前主要操作色保持一致。
- 前景：纸白 `#FFFDF4`，让标记与背景清晰分离。
- 点色：杏色 `#E6B99B`，只用在日光圆点。
- 标准 App 图标为方形、不透明底图；提案中的圆角用于预览。深色、纸白和透明单色版分别提供。
- 名称排版沿用当前系统宋体。图标 SVG 不依赖字体，可直接编辑；标题文字没有打包第三方字体。

## 素材

每个名称分别放在 `yirili/`、`changye/`、`riyu/`：

- `app-icon.svg`、`app-icon-paper.svg`、`app-icon-dark.svg`：三种背景的矢量图标。
- 对应的 `*-1024.png`：1024 × 1024 PNG，App 图标背景不透明。
- `mark.svg`、`mark-reversed.svg`：透明单色与反白标记；提供同名 1024px PNG。
- `context-home.png`、`context-assistant.png`：放入现有手机界面的效果图，786 × 1704。

`index.html` 可切换三个方案、三种图标配色、两个手机场景，并查看小尺寸和单色效果。方案为设计提案，手机场景图通过现有原型生成。

## 名称初筛

本轮检索了候选名称及应用商店结果。「拾常」「日序」已有公开 App 条目，因此未纳入候选：[拾常](https://apps.apple.com/tw/app/%E6%8B%BE%E5%B8%B8/id6740255366)、[日序](https://apps.apple.com/cn/app/%E6%97%A5%E5%BA%8F/id6758913467)。

保留的三个名字未在本轮有限的网页检索中找到明确同名应用；这不是商标、域名或应用商店名称可用性的确认。

## 重新导图

在项目原型服务运行、可解析 Playwright 且已安装 Chrome 的环境执行：

```sh
node ui/brand/tools/export.cjs
```

默认服务为 `http://127.0.0.1:4173`，可通过 `PROTOTYPE_URL` 修改。原型页与设计提案本身不依赖 Playwright。
